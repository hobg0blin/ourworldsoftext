## WORLDS
Worlds is a collaborative canvas project heavily inspired by [Your World Of Text](https://yourworldoftext.com) and [r/Place](https://en.wikipedia.org/wiki/R/place). It is built on top of the [AT Protocol or atproto](https://atproto.com/), a protocol designed to allow users to own their own data. Users' data lives in their own Personal Data Server or PDS. The goal of this application is twofold. First, as a provocation to (hopefully) inspire atproto developers to build graphical/visual/artistic applications, and to inspire software artists to build on top of the protocol. Second, as an exploration of the affordances of the protocol and some of the less obvious and stranger things the tension between decentralized data and "trying to run an app that works" can produce.
